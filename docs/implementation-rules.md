# 구현 규칙 및 원본 확인 사항

## 확정된 규칙

1. 하나의 프로젝트 폴더 안에서 HTML·CSS·JavaScript와 이미지·영상·폰트를 분리합니다. 페이지별 HTML 및 CSS/JS를 구분합니다.
2. 최대 기준은 PC 1920px, 모바일 기준은 402px입니다. 1920px 초과에서는 1920px 콘텐츠를 가운데 정렬합니다.
3. 같은 요소의 수치는 402px 모바일 값과 1920px PC 값 사이에서 선형 보간합니다. 402px 미만은 모바일 값에 `현재 너비 / 402`를 곱합니다. 임의의 14px·16px 최소 글자 크기는 적용하지 않습니다.
4. 화면의 구조가 다른 부분은 1024px을 기준으로 PC/모바일 구성을 바꿉니다. 교수 목록은 4열/2열, 커리큘럼은 학년별 목록/모바일 설명문, 전시는 가로 캐러셀/모바일 3개 세로 카드입니다. 임의의 3열 구간은 없습니다.
5. 폰트 종류·굵기·크기·행간·자간, 이미지 슬롯 및 콘텐츠는 Figma를 기준으로 합니다. 필수 폰트가 없으면 사용자에게 요청하며 다른 서체로 임의 교체하지 않습니다.
6. 요청에 따라 모바일 메인의 회색 전시 이미지 슬롯은 해당 전시에 맞는 포스터로 채웁니다. 슬롯 높이는 414px을 유지하고 포스터 전체가 보이도록 비율을 유지합니다.

## 구현 기준과 Figma 차이

- PC 메인 프레임은 실제로 1919px입니다. 사용자가 지정한 최대 기준 1920px에 맞춰 바깥 너비만 1px 정규화하고, 내부의 기준값은 유지합니다. 그리드의 남는 1px은 브라우저가 열에 배분합니다.
- 모바일 시안 상단의 `IOS/StatusBar` 44px은 기기 UI입니다. 웹페이지에서 가짜 시간·배터리 표시를 중복 렌더링하지 않으며 웹 헤더부터 시작합니다. 따라서 웹페이지 전체 높이의 기준은 시안에서 상태 표시줄 44px을 제외한 값입니다.
- PC에서 큰 소개 영역의 기준 높이는 960px입니다. 모바일에서는 텍스트 줄바꿈에 따라 자연스럽게 높이가 결정됩니다.
- PC/모바일에서 전시 목록의 노출 대상과 문구가 일부 다릅니다. 원본 내용을 유지했습니다. 특히 모바일 3번째 전시는 2020년 전시입니다.
- 교수 사진은 사용자 제공 파일을 해당 인물 순서에 맞춰 배치했습니다. 이미지에 추가 효과나 색 보정을 하지 않았습니다.
- 일부 전시 연도·설명은 원본 내에서 서로 다른 내용이 반복됩니다. 사용자 승인 없이 문구나 일정을 편집하지 않았습니다.
- 정확한 이동 URL·PDF가 아직 없는 항목은 비활성 링크이며, 구성 파일에서 나중에 연결할 수 있습니다.

## 수정 방법

본문은 `index.html`, 스타일은 `css/pages/home.css`, 공통 요소는 `css/common.css`에서 수정하세요. CSS의 `--u`·`--t` 계산과 1024px 구조 전환 조건은 HTML/JS의 영상 전환 조건과 함께 관리합니다. 새 페이지를 만들 때 해당 파일을 `pages/`에 추가하고 공통 스타일·스크립트를 재사용하세요.
